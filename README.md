# Md. Al-Amin — Personal Portfolio

A responsive multi-page portfolio built with HTML5, CSS3 and JavaScript.

## Pages
- Home — introduction and highlights
- About — profile and interests
- Education — current B.Sc. education
- Skills — programming languages and concepts
- Projects — selected projects
- Contact — email and GitHub links, plus a mailto contact form

## Run locally
Open index.html in a modern browser.

## Publish
This repository is intended for GitHub Pages. Enable Pages in Settings → Pages → Deploy from a branch → main → / (root).

## Notes
No achievements, experience, prior education, or proficiency levels were invented. Contact form uses mailto and has no server-side storage. Add the profile portrait asset when the image upload method is available.
