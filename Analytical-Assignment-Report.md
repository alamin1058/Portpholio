# Analytical Assignment Report
## Personal Portfolio Website — Md. Al-Amin

### 1. Introduction
This project is a multi-page personal portfolio website presenting the academic background, technical skills, selected projects, interests, and contact information of Md. Al-Amin, a final-semester Computer Science and Engineering student at Daffodil International University.

### 2. Objectives
- Develop a personal portfolio using core web technologies.
- Organize personal information across multiple pages.
- Apply responsive styling for desktop and mobile screens.
- Demonstrate JavaScript interaction and client-side form handling.

### 3. Technologies Used
- **HTML5:** semantic page structure, navigation, headings, and forms.
- **CSS3:** dark editorial theme, layout, responsive breakpoints, and typography.
- **JavaScript:** mobile navigation, dynamic footer year, and contact form behaviour.
- **mailto:** prepares an email in the visitor's email application; no server-side storage is implemented.

### 4. Website Structure
| Page | Purpose |
|---|---|
| index.html | Landing page and introduction |
| about.html | Personal profile, motivation, and interests |
| education.html | Current degree and university |
| skills.html | Programming languages and software concepts |
| projects.html | Two selected projects |
| contact.html | Contact details and email form |

### 5. Design and User Experience
The website uses a dark editorial visual style with muted green accents and serif display typography. Consistent navigation and footer elements support usability. Responsive CSS and a collapsible mobile menu support smaller screens.

### 6. Functionality
- Navigation links connect all six pages.
- JavaScript toggles the mobile navigation menu.
- Footer year updates automatically.
- Contact form validates required fields and prepares a message through the visitor's email application.
- GitHub profile link opens in a new tab.

### 7. Testing
1. Open index.html and navigate through all pages.
2. Resize the browser and test the mobile menu.
3. Check for horizontal overflow on mobile.
4. Submit the contact form empty and confirm browser validation.
5. Submit valid sample data and confirm the email draft is prepared.
6. Test external links.

### 8. Limitations and Future Improvements
The contact form uses mailto and does not send/store messages on a server. No database or backend is included. The portrait image has not yet been uploaded to the repository. Earlier education, achievements, and work experience were not supplied and are not fabricated. Future work may include project screenshots, a downloadable CV, and a serverless contact endpoint.

### 9. Conclusion
The project demonstrates practical use of HTML5, CSS3, and JavaScript to build a responsive multi-page personal portfolio.
